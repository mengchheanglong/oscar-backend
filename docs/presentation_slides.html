04 / 06 • GOVERNANCE & SAFETY
Human-in-the-Loop Proposal Lifecycle
AI outputs structured drafts; humans inspect, edit, and transactionally commit domain entities
ATOMIC TRANSACTIONAL PERSISTENCE
STAGE 1: DRAFT 📝

AI Draft Proposal

Triggered from a Requirement or Meeting Note. DeepSeek generates structured proposal JSON.

{
"type": "CREATE_TASKS",
"status": "PROPOSED",
"expiresAt": "24h TTL",
"items": [ ...draftTasks ]
}
  • ✓ Validated by strict Zod schema
  • ✓ Private to creator & project scope
  • ✓ ZERO domain records created
State: PROPOSED
STAGE 2: REVIEW 🔍

Human Inspection

User reviews the proposal in an interactive Next.js modal. Every field can be fine-tuned.

☑ Setup PostgreSQL pooler
☑ Configure Argon2id hash
☐ Deprecated legacy task
  • ✓ Deselect unwanted items
  • ✓ Edit titles, descriptions, assignees
  • ✓ Full user editorial control
Option: Click Reject to purge draft
STAGE 3: COMMIT 💾

Transactional Commit

User submits confirmation with an Idempotency-Key header to prevent duplicates.

PostgreSQL Atomic Transaction:
1. Verify Contributor+ permissions
2. Bulk insert Tasks into database
3. Update proposal status → CONFIRMED
4. Append to Activity Audit Stream
  • ✓ Real records inserted in PostgreSQL
  • ✓ Activity stream notified
  • ✓ Rollback on any failure
State: CONFIRMED
