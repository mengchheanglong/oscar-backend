1. High-Level User Journey Diagram
End-to-end user navigation flow across authentication, workspace isolation, grounded AI Copilot, and transactional persistence
ZERO-TRUST GUARANTEE • HUMAN-IN-THE-LOOP
STAGE 1: ENTRY
👤 User Lands on Platform
Visits Web App or IDE extension.
🔒 Authenticated?
Valid session cookie?
NO → LOGIN
🔑 Auth Gateway (/login)
  • Email & Password (Argon2id)
  • Opaque Session Cookie Issued
  • CSRF Token Protection
AUTH OK
STAGE 2: SCOPE
📁 Project Switcher (/projects)
Select or create tenant workspace.
  • Mandatory projectId boundary
  • RBAC: Owner / Maintainer / Contrib / Viewer
  • Conversation memory isolated
CENTRAL HUB
📊 Project Overview Dashboard
Real-time team state aggregates.
  • Task metrics & Overdue tracking
  • Recent Activity Stream audit
  • Document & Knowledge health
USER INTENT
TRACK A: CORE WORKSPACE 📋
Requirements & Task Execution
Direct authoring and lifecycle tracking:
  • Requirements with Acceptance Criteria
  • Architectural Decision Records (ADRs)
  • Tasks, Sprint Priorities & Member Assignment
  • Meeting Transcripts & Document Uploads
TRACK B: AI COPILOT 🤖
Grounded Copilot (/assistant)
Fact-checked project assistance:
  • 6 Specialized Modes (PM, Dev, QA, etc.)
  • Hybrid Retrieval: tsvector + pgvector
  • DeepSeek V4 Pro Generation
  • Verified bracketed citations & source cards
TRACK C: MCP AGENT 🔌
External Coding Agents
IDE tools connected via Model Context Protocol:
  • Cursor / Claude / Antigravity via PAT (aiw_pat_*)
  • Execute list_tasks, get_dashboard, search
PROPOSE
STAGE 4: UNTRUSTED DRAFT
📝 Structured AI Proposal
AI drafts structured task breakdown:
  • Validated by strict Zod schema
  • Status: PROPOSED (24h TTL)
  • Private to creator & project
  • ZERO direct writes to database
HUMAN-IN-THE-LOOP
🔍 Inspection & Editorial Review
Interactive review modal in Next.js UI:
  • ☑ Checkbox item selection
  • Edit titles, descriptions, assignees
  • Click Reject to purge draft
  • Click Confirm to commit
CONFIRM
STAGE 5: PERSISTENCE
💾 Transactional Commit
Atomic PostgreSQL insertion:
  • Idempotency-Key duplicate guard
  • Verify Contributor+ write role
  • Bulk insert validated Tasks / ADRs
  • Proposal status → CONFIRMED
  • Append to Activity Audit Stream
CONTINUOUS LOOP
🔄 Auto-Sync & Feedback
Keeps workspace unified:
  • Triggers background knowledge ingestion
  • Indexes chunks into tsvector / pgvector
  • Refreshes Dashboard metrics & feed
🛡️ The Central Guarantee: User Session → Project Scope Isolation → Grounded RAG with Citations → Human-in-the-Loop Review → Atomic Transactional Persistence.
